# 英语表达练习器 🎯

一个智能英语表达学习工具，帮助你用地道的英文表达日常想法。支持多种练习模式、AI 生成、语音朗读和本地代理服务。

## ✨ 功能特性

### 三种练习模式

1. **选择题模式** 📝
   - 系统生成 4 个中文短语/句子
   - 为每个提供 3 个英文表达选项（最佳 / 可接受 / 错误）
   - 悬停选项显示关键词的中文释义
   - 实时反馈语感等级

2. **填空题模式** 🎪
   - 从 AI 生成的英文句子中提取单词作为空位
   - 提供多个单词选项供选择
   - 悬停单词显示其中文意思
   - 填入答案后显示完整句子

3. **查看模式** 👀
   - 浏览所有 4 个短语的英文表达
   - 查看每个表达的语感等级和解释
   - 复习之前学过的表达

### 核心功能

- **AI 生成**：接入 DeepSeek API，根据中文自动生成地道英文表达
- **语音朗读**：一键播放英文句子的发音（支持男声/女声切换）
- **本地代理**：支持配置代理服务，解决网络访问问题
- **智能识别**：
  - 中文输入 → 自动生成英文表达
  - 英文输入 → 自动翻译为中文并生成表达
- **悬停翻译**：鼠标悬停显示中文释义和关键词翻译

## 🚀 快速开始

### 1. 打开应用
直接在浏览器中打开 `index.html` 文件即可使用

### 2. 配置 API Key
- 点击右上角的 **⚙️ 设置** 按钮
- 在 **DeepSeek API** 标签页中输入你的 API Key
  - 获取地址：https://platform.deepseek.com/
- 勾选 **启用本地代理** 如需使用代理服务

### 3. 开始练习

#### 选择题模式
```
1. 在输入框中输入中文短语（如 "外面下雨了，记得带伞"）
2. 点击 "生成题目" 按钮
3. 悬停在选项上查看关键词释义
4. 点击选择你认为最地道的英文表达
5. 系统会显示答案和解释
```

#### 填空题模式
```
1. 在输入框中输入中文短语
2. 点击 "生成题目" 按钮
3. 悬停在单词选项上查看中文意思
4. 点击选择正确答案填入空位
5. 查看完整的英文句子
```

#### 查看模式
```
1. 在输入框中输入中文短语
2. 点击 "查看表达" 按钮
3. 浏览所有生成的英文表达及其等级说明
```

## 📸 使用示例

### 选择题示例
**中文**：外面下雨了，记得带伞（提示：指随身携带）

**英文选项**：
- ✅ **最佳**：It's raining outside. Remember to **take** an umbrella.
- ⚠️ **可接受**：It's raining outside. Remember to **bring** an umbrella.
- ❌ **错误**：It's raining outside. Remember to **carry** an umbrella.

**悬停 "take" 时显示**：take - 拿；携带

### 填空题示例
**中文**：外面下雨了，记得带伞

**完整英文**：It's raining outside. Remember to ___ an umbrella.

**单词选项**：carry | bring | wear | **take** ✓

## 🎯 学习建议

1. **先用选择题**：理解不同表达的差异和语感等级
2. **再用填空题**：加深对单词搭配的印象
3. **最后查看**：复习所有表达，对比语感等级
4. **定期练习**：每天练习 4-5 个短语，循序渐进

## ⚙️ 设置详解

### DeepSeek API
- **API Key**：从 [DeepSeek 官网](https://platform.deepseek.com/) 获取
- **启用本地代理**：如果无法直连 DeepSeek，勾选此项并配置代理地址

### 语音设置
- **语音开关**：启用/禁用英文句子发音
- **语音速度**：调整播放速度（0.5x - 2x）
- **语音角色**：选择男声或女声

### 高级选项
- **演示题库**：未配置 API Key 时的示例题目
- **刷新生成**：从题库中随机抽取新题目

## 🔧 技术栈

- **前端框架**：原生 HTML5 + CSS3 + JavaScript
- **AI 服务**：DeepSeek API
- **语音合成**：Web Speech API
- **存储**：本地 LocalStorage

## 🐛 常见问题

### Q: 为什么无法生成题目？
**A**: 
- 检查是否填写了 DeepSeek API Key
- 如果在国内，可能需要启用本地代理
- 检查网络连接

### Q: 语音播放没有声音？
**A**:
- 确保浏览器允许音频播放
- 检查系统音量设置
- 尝试刷新页面或切换语音角色

### Q: 如何导出学习记录？
**A**: 目前支持通过浏览器开发者工具查看 LocalStorage 中的记录
