# 英语表达练习器 🎯

一个「表达训练系统」——输入一句中文，给你 **基础表达 / 更自然的说法 / 地道表达** 三档对比，指出中国人常犯的错误，并用进度条、连续答对（streak）、错题本和每日路径帮你坚持下来。

面向**有基础但说不出口**的学习者：每天 10 分钟，练「说出来」，而不是背单词。

## ✨ 功能特性

### 六种模式

| 模式 | 说明 |
|------|------|
| 📅 **每日路径** | 每天固定 10 题，系统安排好练什么，不用自己想 |
| 👀 **查看模式** | 三档表达 + 常见错误 + 使用场景，一次看全 |
| 🎬 **场景表达** | 同一句话的 日常聊天 / 社交媒体 / 正式 / 轻松约会 四种说法 |
| 🌳 **句子搭建** | 从一句简单表达开始，逐步添加信息，拼成整句 |
| 📝 **选择题** | 三句英文选最自然的，答完给对比句和差异讲解 |
| 🎪 **填空题** | 挖空关键单词，选出最贴切的那个词 |

### 训练系统（本次增强的重点）

- **顶部进度条 + 🔥 连续打卡天数** — Duolingo 式进度条显示 `3 / 10`；每天完成一整轮训练记一次打卡，连续天数累积
- **强化反馈** — 答错给：正确答案 + **错误原因**（词汇/语法/语气/搭配）+ **对比句**（你的答案 → 正确说法）；答对补充「更自然的说法」
- **📕 错题本** — 答错自动收录，红色角标提示；「只练错题」有几道练几道、混合题型各用各的渲染器；答对自动移出
- **📅 每日路径** — JSON 配置 7 天课程（基础表达 / 点餐 / 购物 / 出行 / 社交 / 工作 / 综合复习），跨天自动推进
- **🏷️ 场景标签** — 每道题标注场景（日常/点餐/工作/旅行/社交/购物/天气），支持按标签整轮专练
- **📤 分享卡片** — Canvas 生成成绩卡（今日题数 / 命中率 / 连续打卡天数 / 学习日期），可下载或复制图片

### 核心能力

- **AI 生成**：接入 DeepSeek API，任意中文都能生成地道英文表达
- **双向识别**：中文输入 → 生成英文表达；英文输入 → 查词造句
- **语音朗读**：一键朗读（语速三档可调、可自动朗读）
- **悬停翻译**：悬停选项显示关键词中文释义
- **本地代理**：`start.bat` 启动同源代理，绕过浏览器跨域限制
- **离线可用**：不填 API Key 也能跑通全部模式（内置题库 + 演示数据）

## 🚀 快速开始

### 1. 启动

**推荐**：双击 `start.bat`（自动启动本地服务并打开 http://localhost:8080）

**或者**：直接浏览器打开 `index.html`（遇到跨域限制时改用上面的方式）

### 2. 配置 AI（可选，不配也能用）

1. 点右上角 **⚙ 设置** → **AI 连接**
2. 填入 API Key（[platform.deepseek.com](https://platform.deepseek.com/) 申请），点 **保存**
3. 点 **测试连接** 确认可用

### 3. 开始练习

- 想快速上手 → **📅 每日路径**，跟 Day1 走一遍（约 10 分钟）
- 想自由练 → **选择题** / **填空题**
- 想理解表达差异 → **查看模式**
- 想练主动构造 → **句子搭建**

## 📸 使用示例

### 选择题示例

**中文**：外面下雨了，记得带伞（提示：指随身携带）

- ✅ **最佳**：It's raining outside. Remember to **take** an umbrella.
- ⚠️ **可接受**：It's raining outside. Remember to **bring** an umbrella.
- ❌ **错误**：It's raining outside. Remember to **carry** an umbrella.

**悬停 "take" 显示**：take - 拿；携带

**答错后的反馈**：

```
❌ 差一点！这里不适合用 'carry'，换成 'take' 吧。
   你的答案：It's raining outside. Remember to carry an umbrella.
   正确说法：It's raining outside. Remember to take an umbrella.
   错误原因 · 词汇
```

### 句子搭建示例

```
核心句：I want a ___ orange ___.

① 选一个形容词（必选） →  juicy / fresh / sweet
② 选一个场景（可选）   →  for breakfast / after dinner / right now
                      ↓
        I want a fresh orange for breakfast.
```

> 必选 / 可选分开：「可选」成分可以「不添加」，去掉后核心句依然完整；
> 中文按中文语序拼，不会出现 `{0}` 占位符。

### 填空题示例

**中文**：我想吃一个橘子

**完整英文**：I'd like to ___ an orange.

**候选词**：have（吃；享用）| eat（吃）| get（拿到）| take（拿取）

## 🎯 学习建议

1. **每天 10 分钟**：打开就走 **每日路径**，做完分享一下
2. **攻克错题**：攒几道后点 **只练错题**，比反复刷会做的题有用
3. **保持 streak**：🔥 连续打卡天数能明显提升坚持率
4. **从认得到说出**：先用选择题理解差异，再用句子搭建主动搭句子

## 🔧 技术栈

- **前端**：原生 HTML5 + CSS3 + JavaScript（单文件 `index.html`，无构建步骤）
- **AI 服务**：DeepSeek API（OpenAI 兼容协议，可换任意中转站）
- **语音合成**：Web Speech API
- **分享卡片**：Canvas 2D
- **存储**：LocalStorage（进度 / streak / 错题本 / 每日路径 / 统计）
- **本地代理**：Python 标准库 `http.server` + `curl.exe`（`server.py`）

## 🐛 常见问题

**Q: 无法生成题目 / Failed to fetch？**
检查 API Key 是否已保存并测试通过；国内网络建议用 `start.bat` 启动的本地服务方式（同源代理，绕过跨域）。

**Q: 语音没有声音？**
设置 → 语音设置 查看检测结果；缺英语语音包时在 Windows「设置 → 时间与语言 → 语音」安装「英语(美国)」，再刷新页面。

**Q: 顶部进度条不显示？**
进度条只在做题模式（选择题 / 填空题 / 每日路径）出现，查看 / 场景 / 句子搭建不显示是正常的。

**Q: 如何导出学习记录？**
数据都在 LocalStorage，键名见「使用文档.md」的「数据与隐私」一节。
